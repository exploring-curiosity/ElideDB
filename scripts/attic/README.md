# attic — one-off experiments, kept for provenance

These are exploratory scripts: each answered one question once, and the
answer is recorded in BENCHMARKS.md, VIOLATIONS.md or a commit message.
They are NOT maintained, are not imported by anything, and may not run
against the current store schema.

They are kept rather than deleted because several of them are the
evidence behind a MEASURED NEGATIVE — the reason a design was rejected.
Deleting them would leave the conclusion in the docs with nothing behind
it, and this project's rule is that a claim without its measurement is
just an opinion.

Nothing here should be revived without re-running it.
